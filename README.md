# Agri-sage-An-AI-Powered-Ecosystem-for-Precision-Farming
This project focuses on detecting plant leaf diseases using deep learning models.

- ResNet50 is used for image classification (PlantVillage dataset)
- YOLOv8 is used for object detection (PlantVillage + PlantDoc datasets)
- A comparative study is performed to evaluate performance

## Features
- Disease classification and detection
- Multi-dataset training
- Performance comparison

## Tech Stack
- Python
- PyTorch
- Ultralytics YOLOv8

## Results
The models are evaluated based on accuracy and detection performance.
